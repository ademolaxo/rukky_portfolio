Ladder

Ladder is an AI-powered financial assistant that helps users make smarter money decisions through personalized plans and real-time support. I designed a custom illustration system for their rebrand, focusing on app visuals that highlight each of the core financial services.

Collaborators
Role: Illustrator
Company: Moni by Rank
Creative direction: Niyi Okeowo, Unruly studio

Rather than designing icons and singualr splash screen for various actions and product offerings, I approached this as a single visual language that needed to flex across the app.

Each illustration shares the same isometric perspective, color logic, and object vocabulary (coins, notes, containers, paper), so a user moving between features feels like they're staying inside one consistent world rather than moving between disconnected screens.
